Automation Layer

Make.com Scenarios

5 automated workflows handle all background intelligence — no backend code required.

1

Weekly Job Scraper

RapidAPI JSearch → 20 roles × 50 results → OpenAI Prompt 6 extracts skills → Airtable Job_Postings upsert → Skill Demand Index refreshed.

⏰ Every Sunday 00:00 IST
2

Resume Processing Pipeline

New user row in Airtable → fetch resume URL → GPT-4o parses skills → creates Skills_Profile rows → runs gap analysis → sends SendGrid welcome email.

⚡ Airtable webhook (new User)
3

Sprint Generator

New high-urgency gap detected → collect top 3 gaps → GPT-4o generates 7-day sprint JSON → store in Sprints table → email + SMS via SendGrid + Twilio.

⚡ Airtable webhook (new Skill_Gap)
4

Monthly PDF Report

For each active user: calculate readiness delta → generate PDF via PDF Monkey template → deliver via SendGrid attachment.

📅 1st of each month
5

Benchmark Updater

User readiness_score changes → anonymize → write to Benchmarks table → recalculate percentile distribution for bell curve chart.

⚡ Airtable webhook (score updated)
AI Engine

OpenAI Prompt Templates

6 engineered prompts — all return strict JSON for reliable parsing. Model: gpt-4o

PROMPT 1 — Resume Parser
SYSTEM: "You are a precise resume parser. Extract structured data. Return ONLY valid JSON. Schema: { technical_skills: string[], soft_skills: string[], tools: string[], frameworks: string[], projects: [{name, tech[], description}], internships: [{company, role, duration, skills[]}], education: {degree, branch, cgpa} }"
USER: "Parse this resume: {resume_text}"
PROMPT 2 — Gap Analyzer
SYSTEM: "You are a senior hiring manager. Return ONLY valid JSON. Schema: { readiness_percentage: number, verdict: string, missing_skills: [{skill, urgency: 'high'|'medium'|'low', weeks_to_learn, why_important}], strengths: string[], quick_wins: string[] }"
USER: "Student skills: {user_skills_json}. Target role: {target_role}. Market data: {market_skills_json}."
PROMPT 3 — Sprint Generator
SYSTEM: "You are a learning coach. Return ONLY a valid JSON array of 7 objects. Each: { day, focus, topic, resource_type, resource_title, resource_url, time_minutes, mini_task, checkpoint }"
USER: "Create a sprint to learn: {skill_1}, {skill_2}, {skill_3}. Level: {current_level}. Role: {target_role}."
PROMPT 4 — Project Suggester
SYSTEM: "Suggest 5 buildable projects. Return ONLY a JSON array. Each: { title, tagline, difficulty, tech_stack[], core_features[], github_readme_outline[], recruiter_signal, time_to_build_weeks }"
USER: "Student knows: {current_skills}. Learning: {gap_skills}. Role: {target_role}."
PROMPT 5 — LinkedIn Optimizer
SYSTEM: "You are an ATS + LinkedIn specialist. Return ONLY valid JSON. Schema: { headline, about, skills[], keywords_added[], ats_score_estimate_before, ats_score_estimate_after, improvement_tips[] }"
USER: "Role: {target_role}. Headline: {headline}. About: {about}. Skills: {skills_list}."
